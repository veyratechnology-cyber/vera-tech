## What You Need:

### For Email:
1. Resend account (free) - https://resend.com
2. API key from Resend

### For SMS:
1. Twilio account (free $15 credit) - https://www.twilio.com/try-twilio
2. Buy a phone number ($0 with credit)
3. Twilio Account SID and Auth Token

### For WhatsApp:
1. Same Twilio account as SMS
2. Join WhatsApp sandbox (2 minutes on your phone)
